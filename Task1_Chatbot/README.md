# 🤖 TaskBot – Rule-Based Chatbot

## 📌 Overview

**TaskBot** is a simple rule-based chatbot built using Python. It interacts with users by identifying keywords in their input and generating appropriate responses. This project demonstrates the fundamentals of chatbot design and basic Natural Language Processing (NLP) concepts.

---

## 🎯 Objectives

* To understand how chatbots work using simple logic
* To implement conditional statements (`if-elif-else`) in Python
* To simulate basic human-computer interaction

---

## ⚙️ Features

✔️ Greeting recognition (hello, hi)
✔️ Responds to basic questions
✔️ Help guidance for users
✔️ Interactive feature (favorite color)
✔️ Performs simple arithmetic (addition)
✔️ Exit functionality using "bye"

---

## 🛠️ Tech Stack

* **Language:** Python
* **Concepts Used:**

  * Conditional Statements
  * Loops (while loop)
  * String handling

---

## 🧩 How It Works

1. The chatbot continuously takes user input
2. It converts input into lowercase for easy comparison
3. Matches input with predefined conditions
4. Displays corresponding response
5. Repeats until user types **"bye"**

---

## ▶️ Execution Steps

1. Install Python (if not installed)
2. Save the file as `Taskbot.py`
3. Open terminal / command prompt
4. Run:

```bash
python Taskbot.py
```
