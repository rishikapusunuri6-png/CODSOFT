📚 Recommendation System (Python)

A simple rule-based recommendation system built using Python.
It suggests movies and books based on user-selected genres.

---------------------------------------------------
🚀 FEATURES
---------------------------------------------------
- 🎬 Movie recommendations by genre
- 📖 Book recommendations by genre
- 🔁 Menu-driven system (loop)
- ❌ Handles invalid inputs
- 🧠 Uses dictionaries for fast lookup

---------------------------------------------------
🛠️ TECHNOLOGIES USED
---------------------------------------------------
- Python 3
---------------------------------------------------
🎮 HOW IT WORKS
---------------------------------------------------
1. Choose option:
   1 → Movies
   2 → Books
   3 → Exit

2. Select genre
3. Get recommendations instantly
