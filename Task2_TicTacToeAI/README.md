# 🎮 Tic-Tac-Toe AI using Minimax 🤖

## 📌 Overview

This project is an implementation of the classic **Tic-Tac-Toe game** where a human player competes against an AI agent. The AI is powered by the **Minimax algorithm**, making it an unbeatable opponent.

---

## 🎯 Objectives

* To understand the concept of **Game Theory**
* To implement the **Minimax algorithm**
* To simulate intelligent decision-making in games
* To build an interactive command-line game in Python

---

## ⚙️ Features

✔️ Play against an AI opponent
✔️ AI uses Minimax algorithm (optimal moves)
✔️ Detects win, loss, and draw conditions
✔️ Simple and interactive command-line interface
✔️ Unbeatable AI gameplay

---

## 🧠 Algorithm Used

### 🔹 Minimax Algorithm

The Minimax algorithm is a recursive decision-making algorithm used in two-player games. It evaluates all possible moves and selects the best one.

* **Maximizing Player (AI - O):** Tries to maximize score
* **Minimizing Player (Human - X):** Tries to minimize score

### 📊 Scoring System

* AI win → +1
* Human win → -1
* Draw → 0
